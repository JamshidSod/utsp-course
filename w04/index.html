Week 4 · Practical P4 · 2 hours

Low-cost and structural network alternatives for your corridor

Objective

Develop a low-cost improvement alternative and a structural-change alternative for your project corridor, identifying the network connections and constraints that each one addresses (LO3).

Tasks

Task 1. Map the existing layers

On an A3 base map of your corridor (QGIS print layout from tashkent_base.gpkg or LAB04_network.gpkg), mark the walking, cycling, public transport, car and freight networks in different colours. Mark metro stations, main bus stops and the main destinations you identified in Week 1.

Deliverable: A3 map of existing network layers

Task 2. Find missing links and barriers

List every place where a layer is broken: missing crossings, dead ends, canal or rail barriers, gaps between cycle-path fragments, stops without safe access. For each, estimate the detour it causes (network distance minus straight-line distance).

Deliverable: Table of missing links and barriers with estimated detours

#LocationLayerType of breakDetour (m)Who is affected
1
2
3

Task 3. Low-cost improvement alternative

Using only measures that fit within the existing street space and can be built within one year (markings, crossings, signal changes, sidewalk conversion, stop relocation), close as many breaks as possible. Show the changes on a copy of the map.

Deliverable: Map and list of low-cost measures

Task 4. Structural-change alternative

Now allow changes to street space and new infrastructure (new links, bridges, road diet, dedicated bus lanes). State which constraint each measure removes and what it takes away from another user.

Deliverable: Map and list of structural measures with trade-offs

Task 5. Compare

Compare both alternatives with the baseline on: number of breaks closed, continuity of the cycling layer, walking access to the nearest metro station, and approximate cost class (low/medium/high).

Deliverable: Comparison table, to be carried into course-project Stage 2

Materials

  • A3 base map of your corridor
  • LAB04_network.gpkg
  • Coloured pens or QGIS
  • Week 1 indicator list

Assessment

Continuous assessment (LO3): completeness of the break inventory, realism of both alternatives, and a clear statement of the trade-off each one makes.

Week 4 · Laboratory LAB4 · 2 hours · QGIS, Excel (QGIS 3.40 LTR or newer)

Network density, circuity and missing connections

Objective

Calculate network density, route length and circuity ratios in GIS, measure fragmentation of Tashkent's cycle paths, and identify missing connections (LO2, LO3).

Data

FileDescriptionSource
LAB04_network.gpkgLayers: districts (12 study districts), roads (all OSM classes), roads_circuity_districts, footways, osm_cycleways, asl_cycling_network (field-audited network with CEQI), od_origins, od_destinations, od_pairs_straight© OpenStreetMap contributors (ODbL); Normukhammadov (2026)
LAB04_network_metrics.xlsxSheets: Districts (lengths and density formulas), OD_pairs (coordinates, network distances, circuity formulas), Cycle_components, Gap_links_top20 (from the thesis)© OpenStreetMap contributors (ODbL); Normukhammadov (2026)

All GIS layers use EPSG:32642 (WGS 84 / UTM zone 42N). Set the QGIS project CRS to EPSG:32642 before starting.

Steps

Step 1. Set up the project

  1. Project > Properties > CRS: set EPSG:32642 (WGS 84 / UTM zone 42N)
  2. Layer > Add Layer > Add Vector Layer: open LAB04_network.gpkg and add all layers
  3. Style roads by the field highway (Categorized) and districts with no fill

Check: 12 district polygons; the roads layer has about 50,000 features

Step 2. Network density by district

  1. Processing Toolbox > Vector analysis > Sum line lengths: lines = roads, polygons = districts; output field LENGTH
  2. Repeat for footways and osm_cycleways
  3. Open the attribute tables; convert metres to km and compare with the Districts sheet of the workbook
  4. In Excel, check the density formulas (columns F–H) and make a bar chart of road and footway density

Check: Chilonzor road length ≈ 686 km; your QGIS values should match the Districts sheet within 1%

Step 3. Route length and circuity

  1. Processing Toolbox > Network analysis > Shortest path (point to point): network = roads_circuity_districts, path type = Shortest
  2. For pairs 1–3 in Chilonzor and pairs 1–3 in Shayhontohur, pick the start point from od_origins and the end point from od_destinations
  3. Record the route length and compare with the Network distance column in OD_pairs
  4. In OD_pairs, check the straight-line formula (column G) and the circuity formula (column I)

Check: Your six route lengths agree with column H within 2%; the summary rows give the mean circuity per district

Step 4. Sensitivity of the circuity comparison

  1. Sort OD_pairs by circuity; remove the highest value in each district and recalculate the means
  2. Write two sentences: is the difference between the districts robust to one outlier?

Check: State the new means and whether the ranking of the two districts changes

Step 5. Fragmentation of the cycle-path network

  1. Select asl_cycling_network features where facility = 'cycle path' (Select by Expression)
  2. Vector geometry > Buffer: distance 25 m, Dissolve result = yes (selected features only)
  3. Vector geometry > Multipart to singleparts: each part is one connected component
  4. Count the parts and find the largest; compare with the Cycle_components sheet

Check: Number of components and largest component length match the expected results; explain why the thesis reports 149 fragments

Step 6. Identify missing connections

  1. On the components layer, use Vector analysis > Distance to nearest hub (line to hub) or Join attributes by nearest (max distance 200 m) to find pairs of components close to each other
  2. Choose five candidate links in one district; for each, record the gap length and the lengths of the two components it would join
  3. Rank your five links by 'connected length gained per metre built'
  4. Compare with the Gap_links_top20 sheet: the thesis's twenty cheapest links

Check: A ranked table of five candidate links with a one-line justification each

Submission checklist

  • Map of road and footway density by district (PNG or PDF, with legend and source)
  • Completed LAB04_network_metrics.xlsx with your QGIS route lengths added in a new column
  • Component count and largest component, with a short explanation of the difference from 149
  • Ranked table of five candidate missing connections
  • Half a page of limitations: OSM completeness, choice of pairs, buffer tolerance
