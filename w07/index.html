Week 7 · Practical P7 · 2 hours

Two cross-section alternatives and a stop-access layout for your corridor

Objective

Prepare two cross-section alternatives within the same street width as your corridor's existing section, and a stop-access layout for one stop or interchange; explain the trade-offs (LO3, LO4).

Tasks

Task 1. Record the existing cross-section

Choose one representative section of your corridor. Measure every element from building line to building line (footway, planting strip or aryk, parking, lanes, median) with a tape from a safe position, or from a recent satellite image in QGIS (View > Decorations > Scale Bar, then the Measure Line tool). Note the source and date of each measurement.

Deliverable: Dimensioned sketch of the existing section with a data-source note

Element (left to right)Width (m)Measured howNotes (obstacles, trees, parking)

Task 2. Alternative 1 — low-cost reallocation

Keep kerbs where they are. Reallocate with markings, bollards and planters: for example convert parking or one lane to a bus lane or a protected cycle track. The total width must equal the existing width.

Deliverable: Dimensioned cross-section of Alternative 1

Task 3. Alternative 2 — structural change

Allow kerbs to move. You may widen footways, add a planted median with crossing refuges, or build a boulevard. Keep existing mature trees wherever possible and state any you would remove.

Deliverable: Dimensioned cross-section of Alternative 2

Task 4. Stop-access layout

For one bus stop or metro entrance on your corridor, draw a plan (scale 1:500) showing the walking approach from both sides, the crossing, the boarding area, the cycle track route past the stop, cycle parking and shade. Use the island-stop layout from LEC14 or justify another.

Deliverable: Plan drawing of the stop-access layout

Task 5. Trade-offs

Using your LAB7 results, compare existing, Alternative 1 and Alternative 2 on: space share by function, hourly person capacity by mode, crossing distance, and trees kept. Name who gains and who loses in each alternative and what evidence would convince a sceptical stakeholder.

Deliverable: Half-page trade-off statement plus comparison table (carried into project Stage 3, Week 10)

Materials

  • Tape measure or QGIS with a satellite basemap
  • LAB07_cross_sections_synthetic.xlsx as a template
  • A3 paper or Streetmix (optional)
  • LEC14 slides

Assessment

Continuous assessment (LO3, LO4): equal total widths, realistic element widths, a complete stop-access plan and an honest statement of who loses space.

Week 7 · Laboratory LAB7 · 2 hours · QGIS, Excel (QGIS 3.40 LTR or newer)

Cross-sections, person throughput and interchange access

Objective

Draw existing and proposed cross-sections, calculate space allocation and hourly person throughput by mode, and measure walking and cycling access to Tashkent metro stations (LO3, LO4).

Data

All GIS layers use EPSG:32642 (WGS 84 / UTM zone 42N). Set the QGIS project CRS to EPSG:32642 before starting.

Steps

Step 1. Set up the QGIS project

  1. Project > Properties > CRS: set EPSG:32642
  2. Layer > Add Layer > Add Vector Layer: add all layers of LAB07_interchanges.gpkg
  3. Style metro_stations by bus_stops_300m (Properties > Symbology > Graduated) and crossings by control (Categorized)

Check: 49 metro stations and 2,019 bus stops are loaded

Step 2. Bus stops within 300 m of each station

  1. Vector > Geoprocessing Tools > Buffer: input metro_stations, distance 300 m, Dissolve = no
  2. Vector > Analysis Tools > Count Points in Polygon: polygons = buffer, points = bus_stops, count field NUMPOINTS
  3. Open the attribute table and compare NUMPOINTS with bus_stops_300m in the Stations sheet
  4. Vector > Analysis Tools > Distance to Nearest Hub (Points): source = metro_stations, destination = bus_stops

Check: Mean bus stops within 300 m = 3.04; three stations have none; median nearest-stop distance ≈ 98 m

Step 3. Network walking distance for three stations

  1. Processing Toolbox > Network analysis > Service area (from layer): network = walk_network_800m, start points = three stations you choose, travel cost 300 m, path type Shortest
  2. Count bus stops inside the network service area (Vector > Research Tools > Select by Location, then the selection count)
  3. Add a column to the Stations sheet: bus stops within 300 m on the network

Check: Network counts are equal to or lower than the straight-line counts; explain each difference in one sentence

Step 4. Crossings and cycling access

  1. In the Summary sheet, check the formulas for crossings within 300 m and the signalised share
  2. Select by Location: asl_cycle_paths within 500 m of your corridor's nearest station; note the length (Field calculator: $length)

Check: Signalised share of crossings within 300 m = 0.402; 34 stations have a cycle path within 500 m

Step 5. Draw the cross-sections in Excel

  1. Open LAB07_cross_sections_synthetic.xlsx, sheet Cross_sections; check the Total width row (all three = 42.0 m)
  2. Select the element names and the three width columns; Insert > Chart > Bar > Stacked Bar; Chart Design > Switch Row/Column so each bar is one alternative
  3. Colour each element by function (walking, cycling, bus, cars, planting) and add data labels with widths
  4. Replace the Existing widths with your own corridor's measured widths and redesign Alt A and Alt B to the same total

Check: Three horizontal bars of equal length; the Total width row shows the same value in all three columns

Step 6. Space allocation and person throughput

  1. Sheet Space_allocation: check the SUMIF formulas and that each 'sum of shares' cell equals 1
  2. Sheet Throughput: read the capacity by mode and the total for each alternative
  3. Sheet Assumptions: change bus_lane_freq from 40 to 20 and note how Alt A's total changes; then restore it
  4. Replace at least two assumptions with values from your own counts or a cited source and record the source in column D

Check: Example values before your changes: Existing 13,818, Alt A 17,212, Alt B 18,706 persons/h; car capacity falls from 6,318 to 4,212 in Alt A

Submission checklist

  • Stacked-bar drawings of your existing section and two alternatives (equal widths), with a legend
  • Completed cross-section workbook with your widths and at least two sourced or counted assumptions
  • Table of person capacity by mode and space shares for the three sections
  • Map of your nearest metro station: bus stops and crossings within 300 m, straight-line and network
  • Half a page of limitations: capacity vs demand, OSM completeness, station node vs entrances
  • Input data, method, results and limitations are all included (syllabus §6).
